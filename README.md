## 日本語

**Backlog Quick** は、Backlog の課題作成を効率化する Chrome 拡張機能です。

> **注意**: 本拡張機能は非公式であり、株式会社ヌーラボとは一切関係ありません。
> 「Backlog」は株式会社ヌーラボの登録商標です。

### 主な機能

#### ワンクリック課題作成
- 現在のページタイトルと URL を自動取得
- プロジェクト、課題タイプ、優先度、担当者をすばやく選択
- デフォルト設定で繰り返し入力を省略

#### スクリーンショット添付
- ワンクリックで現在のタブをキャプチャ
- 課題に自動添付
- バグ報告や画面共有に最適

#### 画像編集機能（Side Panel モード）
- スクリーンショットに注釈を追加
- 赤枠（四角形）で重要な箇所をハイライト
- 矢印で指示や流れを表現
- テキストでコメントを追加
- Undo/Redo 対応

#### 2つの UI モード
| モード | 特徴 |
|--------|------|
| **Popup** | シンプル・軽量。素早く課題を作成。編集ボタンで Side Panel に切り替え可能 |
| **Side Panel** | フル機能。画像編集機能付き。広い作業スペース |

#### Backlog 課題画面への直接入力
- 拡張機能から Backlog 課題作成画面を開き、入力内容を自動反映

### 対象ユーザー

- Backlog を利用する開発チーム
- バグ報告を効率化したい QA エンジニア
- タスク管理を行うプロジェクトマネージャー

### インストール

[Chrome ウェブストアからインストール](https://chromewebstore.google.com/detail/idgfmkddiglacdmbfkcjbpfjiokfnelf)

### 設定方法

1. 拡張機能をインストール
2. ツールバーのアイコンを右クリック →「オプション」
3. Backlog スペース URL と API キーを入力
4. 「接続テスト」で設定を確認
5. デフォルトのプロジェクト・課題タイプを選択
6. UI モード（Popup / Side Panel）を選択

### セキュリティ

- データはローカルに保存（Chrome の同期機能を除く）
- API キーは Chrome の安全なストレージで管理
- Backlog.com ドメインのみと通信
- 分析、トラッキング、サードパーティサービスなし

## English

**Backlog Quick** is a Chrome extension that streamlines Backlog issue creation.

> **Note**: This is an unofficial extension and is not affiliated with Nulab Inc.
> "Backlog" is a registered trademark of Nulab Inc.

### Key Features

#### One-Click Issue Creation
- Auto-captures current page title and URL
- Quickly select project, issue type, priority, and assignee
- Save default settings to skip repetitive input

#### Screenshot Attachment
- Capture current tab with one click
- Automatically attach to issues
- Perfect for bug reports and screen sharing

#### Image Editing (Side Panel Mode)
- Add annotations to screenshots
- Highlight important areas with red rectangles
- Use arrows to indicate flow or focus
- Add text comments
- Undo/Redo support

#### Two UI Modes
| Mode | Features |
|------|----------|
| **Popup** | Simple & lightweight. Quick issue creation. Edit button opens Side Panel |
| **Side Panel** | Full features. Built-in image editor. Larger workspace |

#### Direct Input to Backlog
- Open Backlog's issue creation page from the extension
- Auto-fill form fields seamlessly

### Target Users

- Development teams using Backlog
- QA engineers streamlining bug reports
- Project managers handling task management

### Installation

[Install from Chrome Web Store](https://chromewebstore.google.com/detail/idgfmkddiglacdmbfkcjbpfjiokfnelf)

### Setup

1. Install the extension
2. Right-click the toolbar icon → "Options"
3. Enter your Backlog space URL and API key
4. Click "Test Connection" to verify
5. Set default project and issue type
6. Choose UI mode (Popup / Side Panel)

### Security

- Data stored locally (except Chrome sync)
- API keys managed in Chrome's secure storage
- Communicates only with Backlog.com
- No analytics, tracking, or third-party services
